# DA-06 — Marketing Campaign Analytics

This repository is being developed as a portfolio-grade marketing analytics case study focused on campaign performance, customer response, channel effectiveness, segmentation, conversion, ROI, and actionable growth insights.

## Data strategy

DA-06 will use a real/public dataset with verifiable provenance and documented source constraints. Large raw files will not be committed to Git. The repository will instead document the source, schema, acquisition steps, cleaning logic, and analytical assumptions.

## Planned scope

- Public/externally sourced marketing dataset
- Data provenance and data dictionary
- Customer/campaign response analysis
- Channel effectiveness and conversion
- Campaign performance and ROI-related metrics where supported
- Customer segmentation for marketing decisions
- Offer/campaign response patterns
- Data quality and cleaning report
- Reproducible Python analysis
- Tests and GitHub Actions CI

> Full development will happen on a dedicated branch before final review and merge.
